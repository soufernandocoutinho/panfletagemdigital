# Panfletagem Digital — Guia Panorama

Página de vendas da **Panfletagem Digital do Guia Panorama**, criada pela **FC Soluções Digitais** para apresentar os planos de divulgação de empresas no **Facebook e Instagram**.

A pagina permite conhecer os benefícios do serviço, comparar quatro opções de investimento e entrar em contato diretamente pelo WhatsApp apresentando informações sobre campanhas patrocinadas, criação de artes publicitárias, segmentação de público e landing page exclusiva para facilitar o atendimento.

## Tecnologias utilizadas

- **HTML5** para estruturação do conteúdo e dados estruturados de SEO.
- **CSS3** para identidade visual, componentes e responsividade.
- **Bootstrap 5.3.3** para a grade, componentes e responsividade.
- **JavaScript** para interações, atualização dinâmica e registro de contatos pelo WhatsApp.
- **WhatsApp** para direcionamento direto de leads comerciais.
- **Google Analytics, Google Tag Manager e Google Ads** para medição opcional de resultados.
- **Meta Pixel** para acompanhamento opcional de conversões no Facebook e Instagram.
- **Cloudflare Web Analytics** para análise opcional de acessos.
- Interface com gerenciamento de consentimento de cookies e tecnologias de rastreamento.

## Sobre o projeto

Este projeto é uma landing page comercial voltada à divulgação e venda dos planos de Panfletagem Digital oferecidos pelo Guia Panorama. Além da apresentação dos planos, a página inclui informações sobre como funciona o serviço, benefícios, perguntas frequentes e chamadas para conversas no WhatsApp.
